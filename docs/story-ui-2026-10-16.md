# 顾客小故事与界面美化 · 2026-10-16

本轮承接 P0 单件模式验收后的试玩反馈。仅更新本地代码和预览，没有推送或部署。

## 已实现

- 50 位顾客按身份重写进店、催餐、好评、差评和争论台词，加入编译、回血、拖堂、银河吃播等梗，并让离店评价呼应进店来意。订单配方、禁料、火候仍单独展示；故事台词不添加真实订单条件。
- 顾客订单卡增加身份首字头像、故事句、催餐状态、耐心条；点卡时由对应顾客回应。超过半程转入催餐句，不扣耐心、不改判单。
- 脏盘取消“脏 N”文字，使用污渍盘、水滴、海绵泡泡三种图标表达待洗、浸泡、刷洗，保留数字数量角标和进度环。
- 冰箱及冷库的八种食材和备用盘改为统一的矢量插画，增加芝麻、肉纹、菜叶纹理、番茄籽、泡菜切片、培根油脂和陶瓷层次。库存数量和缺货状态保留。旧泡菜显示芹菜素材的问题随替换消除。
- 商店、装修列表、墙地颜色选择、外卖/评价弹窗、结算、任务卡、引导统一为奶油纸张、深绿主按钮和暖金点缀。商店按屏幕高度分页，长说明换行，关闭、翻页和购买均有明确区域。
- 按钮增加轻量悬停和按压高亮。使用全局输入的被动观察，避免 Cocos 节点指针事件吞掉厨房的触摸路由；节点销毁时移除监听。
- 结算时立即隐藏新手卡和工位指向标记，避免引导盖住结算操作。

本轮细化的是界面插画；厨房内的 3D 食材模型未整体重做。顾客是单次来店的小故事，尚未增加跨天剧情存档。

## 验证方式

最终构建通过 Cocos Creator 3.8.8 Web Desktop 构建。`pnpm check` 50 个测试文件 / 649 项通过；50 张顾客卡通过 schema 和订单校验。五种窗口尺寸（1280×720、1024×768、1560×720、780×360、587×652）通过商店购买/重复购买拦截、翻页、装修入口、食材取用、卡片回应、三种洗盘图标和弹窗边界检查；另通过模拟触屏购买和已打开商店的窗口缩放。原样预览壳在三种尺寸无滚动和调试覆盖层。真实移动、取料、交餐一单（错单 0）、洗盘和取放投拾回归通过，浏览器异常及失败资源请求均为 0。

## 仍需真人试玩

- 手机横屏：商店字号和长说明是否清楚，拇指点购买/翻页是否轻松；刘海、安全区与微信容器显示是否正常。
- 一边走位做餐、一边看顾客卡：故事句是否好读，是否挡工位；梗是否符合人物、是否太密。
- 只看图标，能否快速区分脏盘、浸泡和刷洗；泡菜、洋葱、番茄是否容易认。
- 主按钮、无法购买、已拥有和缺货状态是否一眼可辨；弹窗开关和长时间游玩是否有卡顿。

当前微信 P0 测试包仍是本轮美化前的版本；这轮以最新 Web 本地预览验收，手机微信效果不能由浏览器截图替代。
