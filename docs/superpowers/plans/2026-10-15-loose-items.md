# 物品自由摆放与投掷实施计划

Goal: 让食材、带盘肉饼、汉堡能够放在地面、投掷并拾回，保持库存、配料、双肉熟度与盘子守恒。

Architecture: 独立零引擎 loose-items 逻辑管理最多 16 组物品；视图复用现有模型，StationView 负责输入和生命周期。碰撞沿用当前布局，短步进飞行，无物理引擎。

Tech stack: TypeScript / Vitest / Cocos Creator 3.8.8。

Spec: `docs/loose-items-design-2026-10-15.md`，用户已要求继续这一阶段。

Global constraints: 保留现有未提交整合；不推送部署；不新增摔盘、污染、顾客受击扣分。单击辅助键放下，长按投掷；空手时地面物品优先，动作键单击拾取、长按清理。货箱、叠盘、配餐、灭火器保留原有操作。物品不阻挡角色。清理带盘食物只将原有盘子转为脏盘。休息/开门前可取料和整理，烹调计时仍停止。

Review focus: 物品和盘子守恒；同时有台面汉堡时不能覆盖；长按不再触发点按；墙、柜、仓库门不可穿越；后台、编辑器、重开与资源释放。

## 验收边界

最多 16 组，不自动删除旧物；满额操作失败保留手持物。双手食材作为一组保留。只在地面放置，不开放柜面堆叠。每日重开清除地面物品并沿用原有重置库存/盘子语义，不跨日存档。桌上有另一份汉堡时提示先腾出台面再拾取地面汉堡；其他食材不受此约束。微信真机触控/帧率仍需设备验证。
